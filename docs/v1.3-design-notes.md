# ScreenGremlin v1.3 interaction polish

Design target: a polished, lightweight desktop companion rather than a wandering overlay.

- Original SVG character art with distinct silhouettes and expressive faces
- Exact park-anywhere behavior (drag then park at that precise location)
- Rope dangle mode with visible rope + hook and adjustable length
- Direct character command bubble: note, todo, remind, snippet, save clipboard
- Cursor/hover reactions and double-click reaction
- Duo choreography remains bounded and event-driven
- No continuous screen capture, microphone, cloud AI, or clipboard monitoring

Competitor learnings used as interaction inspiration only; no third-party character art or franchise assets are copied.
